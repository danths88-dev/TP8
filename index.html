📚 Fundamentos Conceptuales Clave (Teoría Oficial):
• Concepto y Abstracción de Archivo: Unidad lógica de almacenamiento y colección de información relacionada con nombre propio grabada en memoria secundaria; para el SO es una secuencia de bytes (Diapos 3-4).
• Rutas de Acceso: La ruta absoluta consta de la ruta desde el directorio raíz hasta el archivo separando sus componentes con un carácter "separador", mientras que la ruta relativa se toma en relación con el directorio de trabajo o activo (Diapo 9).
• Organizaciones de Archivos: La pila o apilado (registros y campos variables en orden cronológico), Secuencial (longitud fija ordenado por campo clave), Secuencial Indexado (índice + archivo principal + desbordamiento), Indexado (múltiples índices exhaustivos/parciales) y Directo o Hash (Diapos 14-17).
• SCAN de N Pasos: Divide la cola de peticiones en subcolas de longitud N procesadas mediante SCAN; para N grande se aproxima a SCAN y para N = 1 adopta la política FIFO (Diapo 74).

📌 Comparativa Oficial: Mapa de Bits (Diapos 40-41) vs. Lista Ligada de Bloques de Disco (Diapo 42):

• Mapa de Bits (Diapositiva 40): Un disco con n bloques necesita un mapa de n bits (libres = "1", asignados = "0" o viceversa). Generalmente es preferible cuando existe espacio suficiente en la memoria principal para contener completo el mapa de bits.

• Lista Ligada de Bloques de Disco (Diapositiva 42): Los bloques libres se utilizan para contener a la lista de bloques libres, y cada bloque contiene tantos números de bloques libres como pueda. De este modo, aprovecha el propio espacio libre del disco y requiere mucha menos memoria principal que mantener un mapa de bits completo.

3. Operación de Apertura de Archivos y Tabla en Memoria Principal (Diapositiva 8):

Cuando un proceso ejecuta la operación open() sobre un archivo existente, el sistema operativo busca en la estructura de directorios el nombre del archivo, extrae sus atributos y las direcciones de sus bloques en disco, y guarda toda esta información en una tabla en memoria principal. Las referencias subsecuentes al archivo utilizarán directamente dicha tabla en RAM, evitando consultar reiteradamente el almacenamiento secundario.

💡 Ampliación bibliográfica opcional: En sistemas operativos como UNIX, esta gestión se implementa mediante una tabla de descriptores por proceso vinculada a una tabla de descripciones de archivos abiertos del sistema que mantiene el puntero de posición (offset) y el contador de referencias.

2. Técnicas de Comunicación y Capas del Software de E/S (Diapositivas 58-65):
⏳ E/S Programada (Sin interrupciones — Diapos 58 y 62): Transferencia de E/S a memoria a través del procesador. El proceso espera a que termine la operación y la CPU se encuentra ocupada durante todo el proceso de E/S.
⚡ E/S Dirigida por Interrupciones (Con interrupciones — Diapos 59 y 62): Transferencia de E/S a memoria a través del procesador. El procesador emite una orden de E/S, continúa ejecutando las instrucciones siguientes y el módulo de E/S lo interrumpe cuando completa su trabajo.
🚀 Acceso Directo a Memoria (DMA — Diapos 60-62): Transferencia de E/S directa a memoria con interrupciones. Un módulo de DMA controla el intercambio entre la memoria principal y el módulo de E/S; el procesador envía la petición de un bloque de datos al módulo de DMA y se interrumpe solo cuando se ha transferido el bloque entero.
🧱 Capas del Software de E/S y Subsistema del Núcleo (Diapos 64-65):

• Espacio de usuario: Bibliotecas vinculadas con programas de usuario.

• Software de SO independiente del dispositivo: Realiza tareas como el uso del buffer y el reporte de error. El subsistema del núcleo incluye: Buffering (manejar diferencias de velocidad/tamaño), Caching (copias frecuentes en memoria rápida), Spooling (cola de trabajos en dispositivos no multiplexables como impresoras) y Manejo de Errores.

• Drivers de Dispositivos: Se encargan de los detalles de operación de los dispositivos y proporcionan interfaces uniformes para el resto del SO.

• Manejador de interrupciones: Gestiona las interrupciones sobre el hardware.

💾 Caché de Disco (Diapo 81) vs. Disco RAM (Diapo 82):

• Caché de Disco: Buffer en memoria principal (MP) para almacenar sectores del disco; si la petición está en caché se sirve desde allí. Consideraciones de diseño: copia o memoria compartida y estrategia de reemplazo (LRU, LFU).

• Disco RAM (RAM Disk): Porción de MP que actúa como unidad física en la capa de Hardware/Dispositivo (con letra ej. Z: o punto de montaje). El usuario/administrador decide qué archivos guardar; es volátil, estático y de tamaño fijo reservado de antemano.
